# Design system

Identity: **a produce route, not a dashboard.** Warm soil-and-leaf palette, serif display type, a dotted route line (logo mark: two leaves over a dotted path from farm to market). Distinct from siblings: cream paper background, terracotta action colour, chunky 56-72 px controls, icon-led labels.

Tokens: `design-tokens.css` (source), `design-tokens.json` (generated by `tools/tok2json.mjs`), preview `hifi/tokens.html`.

Rule: official and user colours are used for nothing else, so colour alone reinforces (never replaces) the text label.
Contrast: all pairs computed in `contrast-results.md` (0 failures; 4.5:1 text, 3:1 controls).

## Typography
Display: Georgia stack (no web font download, works offline). Body: system UI. Sizes: 18 px body on mobile (16 px desktop), H1 28, H2 21.6, price figures 22-32 bold serif. Numbers are never in light weights.

## Spacing, shape, targets
4/8/12/16/24/32/48 scale. Radius 8/14/22. Targets: primary 56-72 px, minimum 48 px, tab bar 64 px. Measured 44 px minimum on all interactive elements in the click-through.

## Components
Buttons (primary, secondary, clay hero, ghost; sizes block/sm), icon button (48 px), chips (filter, quick-pick), big-choice buttons (quality/stage), stepper (72 px), cards (listing, price, KPI, enquiry), badges (Official, User-submitted, status, quality), banners (offline, synthetic, error), steps (progress/delivery), tabs, table (admin), bar rows (loss/supply), calendar grid, dialog (native `<dialog>`), toast (aria-live), skeleton, empty state, bottom tab bar, side nav.
## Icons
Inline SVG sprite, 2.2 px strokes, rounded caps; every icon has a visible text label (icon-led, not icon-only) except top-bar utilities which have aria-labels.
## Charts
Horizontal bars with the numeric value printed beside each bar; one sparkline with text alternative. No colour-only encoding.
## Motion
Skeleton shimmer only; disabled under prefers-reduced-motion.
## Language
Swahili/English toggle in the top bar, persistent in session. Strings keyed in `prototype/data.js` (I18N). Swahili strings are **drafts and need native-speaker review** before any pilot.
