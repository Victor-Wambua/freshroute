# Wireframes

Low-fidelity grayscale HTML + PNG with numbered annotations, in `wireframes/` (open `wireframes/index.html`). Generated by `tools/build-wireframes.mjs` (a script, so they re-render consistently).

| File | Covers |
|---|---|
| 01-auth-onboarding | language, phone + code, role, farm profile, coop admin sign-in (TOTP) |
| 02-dashboard-navigation | farmer home, buyer market (desktop), coop overview (desktop), bottom tab bar |
| 03-core-workflows | 5-step listing wizard, enquiry + tracker |
| 04-data-entry-offline | loss recording, harvest calendar, offline queue state |
| 05-search-reports | official vs user-submitted prices, compare dialog, loss report + exports |
| 06-notifications-settings-states | alerts + channels, own-data export, member admin, empty/loading/error/success |

Mobile layouts are drawn first (300 px frames); desktop frames only for buyer and coop screens.
